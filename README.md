# 奶娃之旅 · Naiwa's Journey

仿照《超级马里奥》World 1-1 设计的像素风横版闯关速通游戏，主角为像素化**奶娃**，作者 **forgivez**。纯静态 HTML/CSS/JS 构建，无需编译打包，上传 GitHub 后开启 GitHub Pages 即可点开即玩！

## 游戏特色
- **像素化主角与复古画风**：将主角奶娃像素化并制作多帧行走/跳跃/刹车/超级形态动画，搭配像素云朵、山丘、砖块、问号块、绿色水管与终点城堡。
- **经典 World 1-1 玩法**：
  - 踩踏蘑菇怪、踢飞甲壳怪龟壳、顶破砖块
  - 道具：**魔法奶瓶**（变身超级奶娃，可顶碎砖块并多抵挡一次伤害）、**无敌加速星星**、**隐藏 1-UP 绿奶**
  - **隐藏密道捷径**：第 4 根绿水管上按 `↓` / `S` 可进入地下秘密金币房，收集金币后直达终点前！
- **8-Bit 芯片音乐与音效**：内置 Web Audio API 合成的复古背景音乐（地上/地下/无敌星三套旋律）及跳跃、金币、顶砖、踩怪、旗杆结算全套音效。
- **高精度速通计时与实时排行榜**：
  - 精确到毫秒 (`MM:SS.mmm`) 的速通计时器，首次移动开始计时，触碰终点旗杆立即锁表。
  - 支持本地持久化、`BroadcastChannel` 跨标签页实时同步、官方 NPC 基准记录对比，以及可选的云端全球实时同步。

## 一键上传 GitHub Pages 部署步骤
1. 在 GitHub 新建一个公开仓库（例如 `naiwa-journey`）。
2. 将本文件夹内的全部文件（`index.html`、`style.css`、`assets/`、`src/` 等）上传提交到仓库根目录。
3. 打开仓库的 **Settings -> Pages**：
   - **Source** 选择 `Deploy from a branch`
   - **Branch** 选择 `main`（文件夹选择 `/ (root)`），点击 **Save**。
4. 等待约 1 分钟，GitHub 会生成链接 `https://<你的用户名>.github.io/<仓库名>/`，点开即可直接游玩！

## 可选：开启全球跨设备实时排行榜（Supabase 免费方案）
默认情况下游戏已自带**本地持久化 + 同浏览器跨标签页实时同步**。如果希望所有打开 GitHub Pages 链接的玩家共享同一份全球实时排行榜：
1. 在 [Supabase](https://supabase.com) 创建一个免费项目，在 **SQL Editor** 运行以下建表语句：
   ```sql
   create table naiwa_leaderboard (
     id bigint generated by default as identity primary key,
     name text not null,
     time_ms integer not null,
     coins integer default 0,
     score integer default 0,
     route text default '常规通关',
     created_at timestamptz default now()
   );

   alter table naiwa_leaderboard enable row level security;

   create policy "Public read" on naiwa_leaderboard for select using (true);
   create policy "Public insert" on naiwa_leaderboard for insert with check (true);
   ```
2. 将项目的 **Project URL** 和 **Anon Public Key** 填入 `src/config.js` 的 `CLOUD_LEADERBOARD` 中（或直接在游戏右侧「☁️ 云端」按钮里填写），重新提交即可全网实时同步！
